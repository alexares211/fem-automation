Ply Orientation Generator

Single-ply milestone: swaps the fiber orientation in a one-ply .inp, then runs CalculiX on it directly.

Must already have exactly one active ply in the *Shell section, Composite card.
Created automatically if it doesn't exist yet. Leave blank to use the same folder as the input file.
0° = aligned with global X. Step defaults to 15°; type any value for finer resolution.

Angle sweep

Solves every angle in the range, one after another, and records the reaction force at the support for each.

Ply angle is periodic every 180°, so -90..90 already covers every distinct orientation.
Reaction force is read automatically from whichever node set the .inp already has RF history output configured for (falls back to NS_Fixed if none exists) -- no need to type a node set name.
